## 🌟 What Makes Dreamland Special?

### 🌸 1. Liquid Glass & Living Dreamland Atmosphere
- **Cinematic Starlight Theme:** Rich midnight purples, deep violets, and glowing pink cosmos inspired by Japanese digital aesthetics and Apple-level polish.
- **Floating Magical Blossoms:** Subtle, non-distracting floating atmospheric particles creating a serene study sanctuary.
- **Time-Aware Atmosphere:** Dynamically transitions from *Brahmamuhurtha Calm (3 AM)* to *Magical Dawn*, *Radiant Daylight*, *Twilight Dusk*, and *Deep Cosmos*.

### ⚡ 2. Decision Fatigue Eliminator ("What To Do Now")
- No more wondering what to study, whether to switch subjects, or how to organize notes.
- The command center instantly tells you your **exact next action**, complete with a preview of what follows.

### 🔥 3. Strict Study Streak Engine
- **Zero Fake Progress:** Opening the app, browsing pages, or searching subjects **never** increases your streak.
- Your study streak increments **only** when scheduled academic tasks for the day are actually completed ($\ge 80\%$).

### 🌦️ 4. Live Geolocation Weather & IST Clock
- Real-time India Standard Time (IST — UTC+5:30) clock ticking second-by-second.
- Automatic live geolocation weather sync (Temperature, Humidity, Wind, Sunrise, Sunset) with offline caching resilience.

### 📊 5. Advanced Quizzes & Mock Tests Analytics
- Dedicated tracking modules for self-assessment quizzes and full-length mock tests with accuracy trends, averages, and best scores.

## 🚀 Quick Start & Installation

Clone the repository and run locally:

```bash
# Clone the repository
git clone https://github.com/Ursmaax/MY-GATE-CSE-PREP-TRACKER-.git

# Navigate into project directory
cd MY-GATE-CSE-PREP-TRACKER-

# Install dependencies
npm install

# Start local development server
npm run dev
```

## 📦 Deployment (Netlify & GitHub Pages)

This project is fully prepared for lifelong free deployment:

### 🚀 Deploy Instantly to Netlify (Recommended)
Click the button below to deploy your own instance of the Dreamland Command Center to Netlify for free in 30 seconds:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/Ursmaax/MY-GATE-CSE-PREP-TRACKER-)

**Manual Netlify Setup:**
1. Log in to [Netlify](https://app.netlify.com/).
2. Click **Add new site** ➔ **Import an existing project**.
3. Select your repository: `Ursmaax/MY-GATE-CSE-PREP-TRACKER-`.
4. Build settings:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. Click **Deploy Site**!

### 🌐 Deploy to GitHub Pages:
```bash
npm run deploy
```
Your app will be live at: `https://ursmaax.github.io/MY-GATE-CSE-PREP-TRACKER-/`

Your preparation progress, notes, revisions, quizzes, and test scores are securely stored in your browser's local storage. Use **Export JSON Backup** and **Import JSON Backup** in Settings to ensure your data survives device switches for years to come.
